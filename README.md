# Cleoh Lencería

Tienda online propia (migración desde Wix). Stack: Next.js · Supabase · Cloudflare R2 · Mercado Pago · PayPal · Resend · Vercel.

**Producción:** [https://cleoh.vercel.app](https://cleoh.vercel.app)

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Deploy

Ver guía completa: [`docs/DEPLOY.md`](docs/DEPLOY.md)

```bash
vercel --prod
```
